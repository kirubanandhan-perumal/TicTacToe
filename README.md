# Tic Tac Toe

A Java-based Tic Tac Toe game implementing player turns, input handling, and game outcome validation.

## Features

- Two-player Tic Tac Toe gameplay
- Player turn management
- Input validation
- Win condition checking
- Draw condition handling

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Algorithms
- Data Structures

## Project Overview

This project was developed to implement the core logic of a Tic Tac Toe game using Java. The application focuses on game-state management, player interactions, and determining winning and draw conditions.

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- Any Java IDE such as Eclipse, IntelliJ IDEA, or VS Code

### Running the Project

1. Clone the repository.
2. Open the project in your preferred Java IDE.
3. Compile the Java source files.
4. Run the main application class.
